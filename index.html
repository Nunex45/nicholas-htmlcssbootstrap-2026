Página usando HTML com Bootstrap

Bootstrap é um framework utilizado no desenvolvimento de sites, criado para facilitar a construção de páginas bonitas, organizadas e responsivas. Ele oferece componentes prontos, como botões, menus, formulários, tabelas e cards, além de ferramentas para adaptar o site a diferentes tamanhos de tela, como computadores, tablets e celulares.

Com isso, o programador consegue desenvolver páginas de forma mais rápida, sem precisar criar todo o código CSS e JavaScript do zero.

Download

Download Bootstrap to get the compiled CSS and JavaScript, source code, or include it with your favorite package managers like npm, RubyGems, and more.
